Configuração de credenciais de pagamento

Não cole sua API Key nesta página. Esta tela antiga apenas imprimia a chave no console e não a salvava no servidor.

As credenciais do provedor devem ser configuradas exclusivamente nas variáveis de ambiente do backend, nunca em HTML, JavaScript público, localStorage ou console do navegador.

A integração Woovi está temporariamente desativada até o sistema persistir os pedidos, validar os valores fixos do split e autenticar os webhooks. Nenhuma chave precisa ser inserida aqui.
